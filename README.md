# 运行环境
## kotlin版本 - KotlinJavaRuntime 1.8
- 普通项目支持kotlin的方法：
1. Project Structure-》Modules-》Add-》Library-》From Maven
2. 输入地址：org.jetbrains.kotlin:kotlin-stdlib-jdk8:1.8.0 -》点击OK

## 协程版本 - coroutines 1.7.0
- 普通工程中添加coroutines的依赖
1. Project Structure-》Modules-》Add-》Library-》From Maven
2. 输入地址：org.jetbrains.kotlinx:kotlinx-coroutines-core:1.7.0 -》点击OK
